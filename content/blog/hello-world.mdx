This is a starter post written in **MDX**. Posts live in `/content/blog` and are registered in `/data/posts.ts`.

## Writing a post

1. Create `content/blog/my-post.mdx`.
2. Add `{ slug: "my-post", title, description, date }` to `data/posts.ts`.
3. Set `features.blog` to `true` in `data/site.ts` when you're ready to publish.

You can use regular Markdown, code blocks and even React components:

```ts
const answer = 42;
```
